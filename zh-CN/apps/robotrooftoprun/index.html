Robot Rooftop Run

抓起喷气背包，甩开巡逻队，在城市屋顶之间救出你的队友。单指冲刺三条车道，飞越一切危险，击败首领，组装出完全属于你的机器人。

屋顶之城

高架公路在屋顶上方一路延伸，天空开阔，夕阳低垂。然后，机器们从对面涌来。前方的路要由你来清空，而你的队友正等着被解救。

一根手指，三条车道。

一根手指就够了。武器会自动开火，所以你可以把全部注意力放在观察路况上。

按住拖动切换车道

三条车道，一根手指。按住拖动来对准射击、捡起金币，或离开你不想待的车道。

跳跃与滑行

上滑跳过货物，下滑钻过龙门。接下来是哪一种，道路会提前告诉你。

武器自动开火

快递机器人会沿着自己的车道笔直射击。选择车道，就是在瞄准。

蓄满 Overdrive

跑得越稳，Overdrive 蓄得越快。在路况变得凶险的那一刻放出来。

会反击的道路

每一台溜过去的机器都算一次逃脱，第十次逃脱就结束本轮。你不是在逃离什么，而是在守住一条防线。

炸弹机、侦察机与守护者

炸弹机溜过去就会爆炸，侦察机会炮击你所在的车道，守护者会保护周围的敌人。想清楚先打谁。

巡逻队与装甲单位

巡逻队变道拦截，装甲单位开火还击。重型机器逃走按两个计算。跑到后段，整排障碍封住所有车道：只能跳跃或滑行。

首领与解救

击败首领，解救 Echo、Aegis 与 Zip。但要快，否则首领会带着队友逃走。

三大武器系列

选一把适合你读路方式的武器，再用升级和永久专精把它推得更远。

Pulse

均衡的能量弹，好瞄准，容错高。适合用来熟悉道路。

Repeater

快速双发连射。把整条车道打满，在敌群逼近前清掉它们。

Lance

能击穿装甲的重型轨道炮。更慢，但只要瞄准一条直线，装甲单位无一幸免。

拾取道具会改变一条车道的价值：

喷气背包：飞越一切危险，还能自己选择降落车道 磁铁：附近的金币直接吸到身边 Overdrive：蓄满后，在最关键的时刻释放

打造属于你的机器人

你的快递机器人是组装出来的，不是选出来的。每个零件都用路上赚到的金币获得，你装上什么都不会改变难度。

  • 头部、躯干、手臂、腿部、帽子与背包自由组合。
  • 30 位伙伴任你挑。
  • 四种涂装任你挑。
  • 喜欢的造型可存为命名套装。
  • 三大武器系列，支持升级与永久专精。

小小队伍，大大营救。

击败首领，被困的队友就会加入你，并带来一项你可以一直保留的能力。

  • Echo：每第六发子弹会穿透，并且伤害提高 25%。
  • Aegis：抵挡一次攻击，然后重新充能。
  • Zip：召回三台逃脱的机器，并给你一轮连射爆发。

带一位伙伴出战，把它的能力和你的武器搭配起来。把同一位伙伴救出三次，它就会获得薄荷色饰边。

证明自己，然后再回来

街区评级

每个街区按 S 到 C 评级，无失误的街区让接下来的金币翻倍。

超频

开启超频，没有蓝色胶囊、引信更短、高峰时段车流或玻璃核心，金币最高翻倍。

每日全新挑战跑

每天都有一条新的路，所有人都一样，抵达第 3 区还有奖励。

免费游玩，公平游玩。

金币来自道路，不是你的钱包，所有升级都能靠玩获得。任何在售内容都不会改变敌人的血量、难度或你的技术。

无尽模式

一项可选购买，新增没有首领的模式，适合只想享受跑道的玩家。

金币加倍

一次性购买，永久让你赚到的金币翻倍。

金币包

想立刻拿到某个零件时的补充。它能买到的东西，靠玩也都能获得。

为玩家而做

常见问题

什么时候可以玩 Robot Rooftop Run？

现在就可以。Robot Rooftop Run 已在 App Store 上架，支持 iPhone 和 iPad。

Robot Rooftop Run 免费吗？

免费。可选购买包括无首领的无尽模式、永久金币加倍和金币包，所有升级也都可以靠玩获得。

有广告吗？

没有。没有广告，没有体力计时，没有追踪，也无需账号。

怎么操控机器人？

单指操作。按住拖动选择车道，上滑跳跃，下滑滑行。武器会自动开火。

什么会结束一轮？

十次逃脱。每台溜过去的机器都会计数，第十台会结束本轮。

我的进度保存在哪里？

保存在你的设备上。Robot Rooftop Run 不收集任何数据，购买由 Apple 处理。

游戏暴力吗？

不暴力。这是机器人对机器人：失控的机器会炸成火花和螺栓，没有人会受伤，也没有血腥画面。

支持哪些设备？

支持 iPhone 和 iPad。
