Robot Rooftop Run

小小快递员，大大屋顶救援。在悄然失控的城市里，沿着阳光下的天桥一路狂奔，赶在失控机器溜走之前将它们击退，把每一位被困的快递员安全带回家。

阳光下的天桥之城

高架路笔直地跨越屋顶，天空一片开阔，处处是送货好天气般的明快色彩。可接着，机器开始逆向涌来。你是唯一还在奔跑的快递员，前方的路只能靠自己清出来。

单手操作，三条跑道。

一切都靠滑动完成。你从不需要瞄准，所以全部注意力都能放在读路上。

滑动切换跑道

三条跑道，一根拇指。左右滑动对准射线、捡起金币，或离开你不想待的那条跑道。

跳跃与下滑

上滑跃过栏架，下滑钻过门架。路面会提前告诉你下一个是什么，提示总是先于障碍出现。

武器自动开火

快递员会沿着所在跑道自动开火。选择跑道，就是瞄准。

蓄力 Overdrive

Overdrive 会随着你跑得干净利落而不断充能。释放后，你的火力会在四秒内同时穿透三条跑道。挑对释放的时机，就是这局最大的技巧。

十次逃脱，终结本局

生命值很重要，但真正终结你的不是它。每一台从你身边溜走的失控机器都算一次逃脱，第十次逃脱到来时，城市就会被彻底占领，本局随之结束。这一条规则，把一款无尽跑酷变成了一份差事：你不是在逃跑，而是在守住一条防线。

赛道逐步升级

滚轮机、跳跳机、螃蟹机、飞行机和装甲车会以远远就能看出规律的阵型出现，而且一路上一个街区比一个街区更凶。

头目战

运货门架会带着横跨三条跑道的锁一同来袭。打破锁，挑好目标，别在忙着开锁时放过任何一个。

把它们拉回来

逃脱不是终点。合适的伙伴能力可以召回从你身边溜走的机器，把你以为已经输掉的这一局再买回来。

三大武器系

选一款最适合你读跑道习惯的武器，然后把它升满三级。升级拱门会在途中出现在路面上，所以你是在跑的同时，一路决定自己的打法。

Pulse

均衡的能量弹，容易瞄准也容错。用它来熟悉赛道最合适。

Repeater

双管速射。用弹幕填满一条跑道，能在敌群逼近前先清空它们。

Lance

重型轨道炮，能击穿装甲。射速较慢，但只要打中一条直线，没有装甲能扛得住。

奔跑途中的拾取道具，会改变一条跑道的价值：

喷气背包 — 飞越三条跑道，再挑一条降落 金币磁铁 — 金币自动飞向你 Overdrive — 穿透三条跑道

Workshop

你的快递员是组装出来的，不是挑选出来的。每个槽位都各自独立，每个部件都要用跑道上赚来的金币换取，装上去的东西不会改变数值——它改变的是奔跑的这个人是谁。

  • 头部、胸甲、手臂、腿部、帽子和背包，各自独立更换。
  • 目录里有数十种部件，全部都能靠游玩获得。
  • 点一下部件，实时预览上身效果；再点一下即可装备。
  • 保存命名套装，一键切换整体造型。
  • 给伙伴们换上专属皮肤，让整支队伍风格统一。

小小队伍，大大救援。

天桥之上，总有快递员被困在路中央。靠近一个，它就会加入你——并带来一项你会一直保留的能力。

  • Echo — 每第六发子弹会穿透，且伤害提高 25%。
  • Aegis — 直接格挡一次命中，随后重新充能。
  • Zip — 召回四次逃脱，并赐予你一阵速射冲刺。

带一位伙伴出发，把它的能力和你的武器搭配起来。同一位伙伴救三次，就能解锁它的薄荷配色。

每日任务

每天都有一组全新的救援任务，每个都能换金币。两三局就能全部完成。

两种模式

Rescue Run 是包含头目战的完整战役，免费内置。Endless Delivery 则去掉了头目，留给只想专心跑路的玩家。

值得追逐的目录

部件、套装、伙伴皮肤和武器等级都需要金币，而金币只能靠奔跑赚取。总有一件东西差一点点就能到手。

免费畅玩，公平畅玩。

Robot Rooftop Run 免费游玩，完整战役也都在免费内容里。付费内容不会让路更好读，也不会让机器更好打。

Endless Delivery

一次性的可选模式解锁。永久生效，可恢复购买，且与免费战役完全独立。

金币翻倍

一次性购买，永久让你赚到的金币翻倍，适合想更快集满目录的玩家。

可选金币包

想立刻拿到某个部件时，可以用它补充金币。它能买到的一切，也都能靠游玩获得。

为玩家而打造

无广告没有打断，没有要硬着头皮看完的视频，也没有奖励门槛。
无追踪无统计分析，无第三方 SDK，不收集任何数据。
无需账号你的进度保存在设备本地。

常见问题

什么时候可以玩到 Robot Rooftop Run？

Robot Rooftop Run 即将在 App Store 上线，支持 iPhone 和 iPad。上线后我们会第一时间在此页面附上链接。

Robot Rooftop Run 免费吗？

是的。Rescue Run，也就是完整的头目战战役，免费内置。Endless Delivery 是一项可选的一次性模式解锁，此外还有可选金币包和永久金币翻倍。每一个部件、套装和武器升级都可以靠游玩获得。

有广告吗？

没有。无广告、无追踪、无需账号。

如何操控机器人？

一根拇指就够。左右滑动切换跑道，上滑跃过栏架，下滑钻过门架。武器会自动开火，你的拇指只需要专心跑。

什么情况会结束本局？

十次逃脱。每一台从你身边溜走的失控机器都算一次，第十次就会结束本局。掉血会让你难受，但真正终结你的是逃脱次数。

我的进度保存在哪里？

保存在你的设备上。Robot Rooftop Run 不收集任何数据，购买由 Apple 处理。

游戏暴力吗？

不会。失控机器被击中后会化作火花和螺栓四散，没有角色会受伤，也没有任何血腥画面。

支持哪些设备？

iPhone 和 iPad。
