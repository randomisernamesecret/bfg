Robot Rooftop Run

小さな配達員による、大きな屋上の救出劇。陽光あふれるスカイウェイの街を駆け抜け、暴走マシンがすり抜ける前に撃ち落とし、はぐれた配達員をひとり残らず連れ帰ろう。

片手で操作 ロボットWorkshop クルー仲間 ボスバトル 広告なし iPhone・iPad

陽光あふれるスカイウェイの街

高架道路は屋上の上をまっすぐに伸び、空は大きく開けていて、すべてが気持ちのいい配達日和の色をしている。そこへ、逆方向からマシンたちがやって来る。まだ走り続けている配達員はあなただけ。この先の道を切り拓くのは、あなたしかいない。

親指ひとつ。3つの車線。

すべてはスワイプひとつ。狙いを定める必要はなく、意識のすべてを道を読むことに集中できる。

スワイプで車線を変える

3車線を、親指ひとつで。横にスライドして射線を合わせたり、コインを拾ったり、いたくない車線から抜け出したりしよう。

ジャンプとスライド

ハードルの上へはスワイプアップ、ゲートの下へはスワイプダウン。どちらが来るかは道が教えてくれて、合図は障害物より先に現れる。

武器は自動で発射される

配達員は自分の車線にまっすぐ、自動で撃つ。車線を選ぶことが、そのまま狙いになる。

Overdriveを溜める

Overdriveはノーダメージで走るほど溜まっていく。解放すれば4秒間、3車線すべてを貫通する弾を撃てる。使いどころを見極めることが、このゲームの腕の見せどころ。

10回の見逃しでランが終わる

体力も大事だが、あなたを倒すのはそれだけじゃない。すり抜けた暴走マシンは1回ごとに「見逃し」としてカウントされ、10回目の見逃しで街は制圧され、ランは終わる。このルールひとつが、エンドレスランナーを「仕事」に変える。逃げているのではない、あなたは最前線を守っているのだ。

道はどんどん激化する

ローラー、ホッパー、クラブ、フライヤー、装甲ローバー。遠くからでも読み取れるパターンで現れるが、地区が進むごとに手強くなっていく。

ボスバトル

貨物ゲートが3車線すべてにロックを構えて迫ってくる。ロックを破壊し、狙いを定め、手が離せない間もすり抜けを許さないように。

引き戻せ

見逃しても、それで終わりとは限らない。適切な仲間の力で、すり抜けたマシンを呼び戻し、諦めかけたランを取り戻せる。

3つの武器ファミリー

自分の車線の読み方に合う武器を選び、3段階のアップグレードを重ねよう。アップグレードゲートはラン中の道に現れるので、走りながらビルドを選ぶことになる。

Pulse

バランスの取れたエネルギー弾。狙いやすく、扱いやすい。道を覚えるならこれから。

Repeater

高速の2連射。車線を弾で埋め尽くし、群れが迫る前に一掃する。

Lance

装甲を貫く重レール弾。発射は遅いが、まっすぐ当てれば装甲マシンも生き残れない。

ラン中のパワーアップが、車線の価値を変える：

ジェットパック — 3車線すべての上を飛び、着地する車線を選べる コインマグネット — コインが向こうから寄ってくる Overdrive — 3車線すべてを貫通

Workshop

配達員は選ぶものではなく、組み上げるもの。スロットはそれぞれ独立していて、パーツはすべて道で稼いだコインで手に入る。何を取り付けても数値は変わらない ── 変わるのは、走っている「その人」だ。

  • 頭部、胸部、腕、脚、キャップ、パックをそれぞれ個別に付け替えられる。
  • カタログには数十種類のパーツ。すべてプレイして手に入る。
  • パーツをタップすればロボットにその場でプレビュー表示。もう一度タップで装備。
  • 名前を付けたキットを保存すれば、見た目を丸ごとワンタップで切り替えられる。
  • 仲間にも専用スキンを与えて、クルー全体でスタイルを揃えよう。

小さなクルー。大きな救出。

スカイウェイの途中には、立ち往生した配達員がいる。たどり着けば仲間になり ── そのまま使い続けられる力を連れてきてくれる。

  • Echo — 6発ごとに貫通弾、ダメージも25%アップ。
  • Aegis — 一撃を完全に防ぎ、その後チャージし直す。
  • Zip — 見逃し4回分を呼び戻し、連射の猛攻を与えてくれる。

1回のランには仲間をひとり連れて行き、その力を武器と組み合わせよう。同じ仲間を3回救出すると、ミントカラーの装飾が解放される。

また戻ってきたくなる理由

デイリー任務

毎日新しい救助クエストが登場し、それぞれコインがもらえる。2〜3回のランでクリアできる。

2つのモード

Rescue Runはボスバトル付きのキャンペーンで、最初から遊べる。Endless Deliveryはボスを省いて道だけを楽しみたいプレイヤー向け。

追いかけたくなるカタログ

パーツ、キット、仲間のスキン、武器のレベル。すべてコインが必要で、コインは走ることでしか手に入らない。あと少しで届きそうなものが、いつもひとつある。

基本無料。そして、フェアに。

Robot Rooftop Runは無料で、キャンペーン全体が無料版に含まれている。販売されているものの中に、道を読みやすくしたりマシンを当てやすくしたりするものはない。

Endless Delivery

任意の買い切りモード解放。永続的で復元可能、無料キャンペーンとは完全に別物。

コインダブラー

一度購入すれば、獲得コインが永久に2倍になる買い切りアイテム。カタログを早く埋めたいプレイヤー向け。

任意のコインパック

今すぐそのパーツが欲しいときのための追加チャージ。買えるものはすべて、プレイして手に入れることもできる。

プレイヤーのために

広告なし中断も、見なければいけない動画も、リワード制限もありません。
トラッキングなし分析ツールなし、サードパーティSDKなし、データ収集なし。
アカウント不要進行状況はあなたのデバイスに保存されます。

よくある質問

Robot Rooftop Runはいつ遊べますか？

Robot Rooftop RunはiPhoneとiPad向けに、近日App Storeで配信予定です。配信が始まり次第、このページにリンクを掲載します。

Robot Rooftop Runは無料ですか？

はい。ボスバトル付きの本編キャンペーンRescue Runは無料で、最初から遊べます。Endless Deliveryは任意の買い切りモード解放で、ほかに任意のコインパックと永久コインダブラーがあります。パーツ、キット、武器アップグレードはすべてプレイして手に入れられます。

広告はありますか？

ありません。広告なし、トラッキングなし、アカウント不要です。

ロボットはどう操作しますか？

親指ひとつです。左右にスワイプして車線を変え、上にスワイプしてハードルを飛び越え、下にスワイプしてゲートの下をすり抜けます。武器は自動で発射されるので、親指はずっと走りに集中できます。

ランはどうやって終わりますか？

10回の見逃しです。すり抜けた暴走マシンはすべてカウントされ、10回目でランが終わります。体力を失うのも痛手ですが、あなたを終わらせるのは見逃しの数です。

進行状況はどこに保存されますか？

お使いのデバイスに保存されます。Robot Rooftop Runはデータを一切収集せず、購入はAppleが処理します。

暴力的な表現はありますか？

いいえ。暴走マシンは火花とボルトになって弾けるだけです。傷つく人はおらず、流血表現もありません。

対応デバイスは？

iPhoneとiPadです。
