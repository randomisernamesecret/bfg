Cognithix vs Atom Learning：2026年、ご家庭に合う11+対策はどちら？

2026年9月 · 読了8分 · 教育

お子さまの11+の準備を進めていると、Atom Learning の名前はまず目に入るはずです。イギリスの入試対策で最もよく知られたサービスの一つで、35万以上の家庭に信頼されているとしています。Cognithix はそれよりずっと小さく、性格もかなり異なるアプリです。iPhone と iPad で使え、データはすべて端末内に保存され、支払いは一度だけです。どちらもお子さまの準備にしっかり役立ちます。ただ、両者は何を優先し何をあきらめるかが異なり、その違いは機能の一覧よりもずっと大切です。

はじめにお断りしておくと、Cognithix は私たちが開発しています。Atom Learning についてはできるだけ公平に書くよう努めました。同社に関する記述はすべて、2026年9月時点の同社ウェブサイトと App Store の掲載情報に基づいています。料金やプランは変わることがあるので、決める前に両方を確認してください。参考書、アプリ、家庭教師まで含めて広く比べたい場合は、2026年版 11+対策ガイドもご覧ください。

要点のまとめ

  • Atom Learning を選ぶとよいのは、数学も同じサービスで対策したい、スマートフォンやタブレットだけでなくパソコンでも練習したい、端末間で進捗を同期したい、あるいは11+の後も GCSE まで続けて使えるサービスがほしい場合です。
  • Cognithix を選ぶとよいのは、アカウント登録なし、月々の支払いなし、端末の外にデータを出さずに iPhone や iPad で英語と推論の練習をしたい場合、またはお子さまの志望校が言語適性テストで入学枠を設けている場合です。
  • Cognithix に数学の教材を組み合わせるのは、お子さまの試験に数学が含まれる場合です。Cognithix は数学をまったく扱っていません。

Atom Learning の概要

Atom Learning は7〜16歳を対象としたオンライン学習プラットフォームです。ブラウザ版から始まり、2026年8月からは Atom のアカウントを持つ家庭向けに iPhone・iPad アプリも提供しています。主な内容は次のとおりです。

  • 科目：英語、数学、理科。入試対策プランでは言語推論（VR）と非言語推論（NVR）が加わります
  • 対象試験：グラマースクールの11+、私立校の入学試験、ISEB Common Pre-Tests、CAT4、さらにその先の GCSE
  • アダプティブ学習：お子さまのレベルに合わせて問題が調整され、週ごとの個別プランが用意されます
  • 模擬テスト：最上位プランではオンライン模擬テストが無制限
  • 保護者向け画面：保護者が進捗を確認できる「Track」ページ
  • 対応端末：ブラウザが使えるパソコンやタブレット、および iPhone・iPad アプリ。進捗はアカウントを通じて同期されます
  • 料金：英語・数学・理科は月額 £39.99、言語推論と非言語推論が加わる Exam Prep は月額 £59.99、無制限の模擬テストが加わる Exam Prep Plus は月額 £69.99。年払いにすると20%お得になり、Exam Prep の場合は年額 £575.90 です。

完成度が高く実績のあるサービスで、対応範囲の広さは紛れもない強みです。一つのサブスクリプションで、小学校段階の練習から11+、そして GCSE の復習まで続けて使えます。

Cognithix の概要

Cognithix は、11+の準備をしている9〜11歳のお子さま向けの iPhone・iPad アプリです。主な内容は次のとおりです。

  • 科目：英語（語彙、スペリング、文法、句読法、読解、穴埋め）、言語推論（11トピック）、非言語推論（8トピック）、言語適性
  • 数学なし：数学はあえて扱っていません
  • 毎日のプラン：短いプランが次に練習する内容を提案し、日ごとにトピックを変えます
  • アダプティブ学習：練習中に難易度が調整され、問題にはヒントと答えの解説がつきます
  • 時間を計るテスト：科目ごとのフルペーパー、ハーフペーパー、スピードラウンド、テーマ別テスト
  • やる気の支え：練習でコインを集めてバーチャルペットのお世話ができるほか、星、バッジ、連続記録もあります
  • 保護者向け画面：お子さまごとのプロフィールで、1週間の学習時間・セッション数・正答率、習得済みのトピックと復習が必要なトピック、急いだ解答や成績の下降傾向といったパターンを確認できます
  • アカウントとデータ：アカウントは一切不要。プロフィールと進捗は端末内にのみ保存され、私たちに送信されることはありません
  • 料金：7日間無料、その後は £9.99 の一度きりの購入で、すべてのお子さまのプロフィールが使えます。サブスクリプションも広告もありません。

Atom より新しく小規模なアプリで、役割も絞られています。スマートフォンやタブレットで毎日短時間、英語と推論を練習すること、そして保護者の手間をできるだけ減らすことです。

まず見ていただきたいのは科目の行です。ほとんどのグラマースクールの試験には数学が含まれ、Atom は数学に対応していますが、Cognithix は対応していません。お子さまの試験に数学がある場合、Cognithix は対策の一部にしかなりません。

Atom Learning が優れている点

数学と理科。Atom は英語と推論に加えて数学も扱っているため、一般的な4科目の11+を一つのサブスクリプションでカバーできます。Cognithix を使う場合、数学には問題集や別のツールが必要です。

パソコン対応と同期。Atom は Apple 製品だけでなく、Windows ノートパソコン、Chromebook、Android タブレットでもブラウザで動作し、進捗はどの端末にも引き継がれます。Cognithix は iPhone と iPad のみで、進捗は端末ごとに別々に保存されます。

11+の先まで使える。Atom は ISEB Common Pre-Tests、CAT4、私立校の入試、さらに GCSE の対策にも対応しています。複数年にわたり、複数の試験に一つのサービスで備えたい場合、この継続性は大きな価値があります。

規模と実績。利用者が多いため、申し込む前に参考にできる保護者のレビューやフォーラムでの議論が豊富にあります。新しいアプリには、まだそれを積み重ねる時間がありません。

Cognithix が優れている点

長い準備期間でのコスト。12〜18か月かけて準備する家庭も少なくありません。Cognithix は1か月使っても2年使っても費用は同じで、一度の購入でその端末上のすべてのお子さまのプロフィールが使えます。

アカウント不要、データは端末の外に出ない。メールアドレスやパスワードの設定は必要ありません。プロフィール、解答、進捗は iPhone や iPad の中にとどまり、私たちに送信されることはありません。保護者用 PIN によって、設定と購入は大人が管理できます。その代わり、進捗を別の端末に移すことはできません。

インターネット接続が不要。接続がなくても練習できるので、移動中や Wi-Fi が不安定な場所でも役立ちます。

言語適性の練習。語学を専門とする少数の学校では、Year 7 の入学枠の一部を言語適性テストで決めています。Cognithix には、音のヒントや単語の組み合わせから、数の学習、文の組み立てまで、この種の課題に取り組む独立した科目があります。Atom は言語適性を科目として挙げていません。どのような学校がこのテストを実施しているかは、言語適性テストのガイドで解説しています。

毎日の短い習慣づくりのための設計。毎日のプラン、お世話が必要なペット、短いセッションは、スマートフォンやタブレットで1日10〜15分取り組むことを前提にしています。Atom にも独自のごほうびや達成目標の仕組みがあるので、どちらのスタイルがお子さまに合うかで判断してください。

一度計算してみる価値があります：Atom の Exam Prep の料金では、1年間の費用は月払いで £719.88、年払いで £575.90 です。Cognithix は £9.99 の一度きりですが、お子さまの試験に数学が含まれる場合は、問題集一式など数学の教材も別に必要です。表示価格だけでなく、必要なものすべてを合わせた費用で比べてください。

どちらのアプリにもできないこと

幅広い読書に代わるアプリはありません。英語と言語推論の得点を支える語彙力は、読書によって育ちます。また、どちらのアプリも、お子さまが受ける試験の正確な形式までは教えてくれません。それを知る手がかりは学校やコンソーシアム（学校連合）にあり、その多くが試験形式に慣れるための無料の練習問題（familiarisation paper）を公開しているので、まずはそれを入手しましょう。さらに、お子さまの試験に作文の課題がある場合は、どちらのアプリを選ぶにしても、紙とペンで練習するのが一番です。

お子さまが実際に受ける試験の種類も確認しておきましょう。状況は近年大きく変わっています。何が変わったのか、どう確認すればよいかは、2026年版 GL vs CEM のガイドで解説しています。

どちらを選ぶべきか

Atom Learning が合っている可能性が高いのは…

  • お子さまの試験に数学が含まれ、すべてを一か所で済ませたい
  • お子さまがパソコン、Chromebook、Android タブレットで練習する
  • 端末が変わっても進捗を引き継ぎたい
  • 11+の後も続けて使えるサービスがほしい

Cognithix が合っている可能性が高いのは…

  • 家族で iPhone や iPad を使っていて、毎日短時間の練習をさせたい
  • 月額のサブスクリプションより、一度の支払いのほうがよい
  • アカウントを作ったり、お子さまのデータをオンラインに保存したりしたくない
  • お子さまの志望校が言語適性テストで入学枠を設けている
  • 数学はすでに問題集や家庭教師でカバーしている

すべてをカバーする低予算の組み合わせ

英語・推論・言語適性には Cognithix、数学には Bond や CGP の問題集一式。この組み合わせなら、一般的な4科目の11+を、大手サブスクリプションの1か月分より少ない費用でカバーできます。

まとめ

Atom Learning も Cognithix も、準備の方法として十分に妥当な選択肢です。Atom は対応範囲が広く、数学も扱い、端末間で同期できますが、その分を毎月支払います。Cognithix は範囲を絞り、プライバシーを重視した設計で、支払いは一度だけですが、数学は別の方法で対策する必要があります。どちらも近道ではありません。短い練習を続けること、たくさん本を読むこと、十分な睡眠、落ち着いた家庭環境のほうが、どのアプリよりも大切です。

どちらにも無料体験があるので、いちばん簡単な確かめ方は、お子さまにそれぞれ数日ずつ試してもらい、言われなくても自分から開くのはどちらかを見ることです。最適なツールとは、これからの数か月間、お子さまが実際に着実に使い続けるものです。

11+の準備を進めていますか？

Cognithix なら、英語、言語推論、非言語推論、言語適性の練習をひとつにまとめられます。アカウントもサブスクリプションも不要です。
